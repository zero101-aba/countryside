## 二、仓库简介（About，中等长度）

```
《田园小镇》是一个手机端的像素风种田小游戏原型。
你不是亲手种地的人，而是"东家"：一句话下令，村民自己判断、自己走过去、自己动手，整个过程都看得见。
两位主角各有性格、情绪、需求和自主意愿，会自己干活、去集市买卖、用大模型聊天发展关系；
游戏分 8 个阶段，每达成一个阶段就解锁新玩法；还有天气、昼夜、牧场、服装店、委托与成就。
纯前端 Canvas + 原生 ES Module，无框架、无后端、无外部美术素材。
```

## 三、详细介绍（README 顶部可用的开头）

> 参考星露谷的田园氛围，但核心不是"点一下就收获"。

**说话即玩法。** 底部常驻输入框，聊天和下令共用一个入口：`小伟把3号地浇一下`、`把干的地都浇了`、`小杨别浇了去钓鱼`。没有指定人时会按空闲程度、喜好、距离和精力自动派活；忙的人排队，做完自动接下一单。

**活的人，不是工具。** 小伟嘴甜心宽、爱清闲；小杨心细、爱干净、认真。两人各有 5 条独立情绪、饱食/精力/社交需求和信任值。没活的时候，他们会去河边坐坐、看看花、收拾院子、找对方聊天——小杨还会自己判断种子不够，走去集市买种子；小伟会看到仓库堆货或缺钱，主动去卖东西。你一发指令，他们立刻放下自己的念头先干你的活。

**看得见的执行。** A* 寻路、绕开障碍、锄头起落、水花木屑、进度环、头顶想法气泡和实时汇报；点地图上的角色，视角会跟着他移动。

**会成长的村子。** 8 个阶段逐渐解锁委托板、牧场指令、8× 速度、后山挖矿、鱼价加成、矿石加成、AI 自动对话和荣誉称号；5 个区域可自由前往，64×52 无缝大地图；5 种作物、11 种动物、天气与昼夜、服装店 10 套时装。

**可选的 AI 角色对话。** 接入火山方舟 / DeepSeek 后，小伟和小杨会自己聊天，影响情绪、信任和关系值；没配 Key 也能玩全部本地内容。

## 四、功能亮点

- 🗣 **自然语言指令**：指定人 / 批量 / 范围 / 序号 / 模糊反问 / 改令 / 停止
- 🧠 **村民 AI**：性格、情绪、需求、记忆、信任、自主意愿、关系里程碑
- 🛒 **自主经济**：小杨自己买种子，小伟自己卖库存
- 🎭 **AI 对话**：火山方舟 / DeepSeek，可自动或手动触发
- 🌾 **农业**：5 种作物、四阶段成长、湿润生长、季节限制
- 🐔 **牧场**：11 种动物、鸡蛋/牛奶/羊毛、收牧产指令
- 🗺 **地图**：64×52 无缝世界、5 区域、解锁与快速前往、挖矿
- ⛅ **世界**：晴/雨/暴雨、三层雨丝与闪电、昼夜光照、四季
- 🏆 **成长**：8 阶段解锁、12 个成就、每日委托、每日小结
- 👕 **服装店**：每人 5 套时装，按阶段解锁购买，实时换装
- 📱 **手机优先**：竖屏/横屏、PWA 添加到主屏幕、离线缓存
- 🎨 **零素材**：所有像素画面与界面都由代码绘制

## 五、技术栈

| | |
|---|---|
| 语言 | JavaScript（原生 ES Module，无框架） |
| 渲染 | Canvas 2D 低分辨率缓冲 + 整数放大 + `image-rendering: pixelated` |
| UI | DOM 覆盖层 + CSS（奶油纸质主题） |
| 寻路 | 自研 A*（八方向、避农田、不穿角） |
| 存档 | localStorage |
| 服务器 | Node.js 极简静态服务 + `/api/ark`、`/api/deepseek` 代理 |
| AI | 火山方舟（Ark）/ DeepSeek，可选 |
| 测试 | puppeteer-core + 本机 Edge，无头冒烟与功能测试 |

## 六、快速开始

```bash
npm install        # 只有测试需要依赖；运行游戏本身零依赖
npm run dev        # http://localhost:5180
npm run build      # 生成 dist/
```

手机体验：电脑运行 `npm run dev`，手机同一 Wi-Fi 打开 `http://<电脑IP>:5180/`，浏览器菜单「添加到主屏幕」。

AI 对话（可选）：

```powershell
$env:ARK_API_KEY="你的方舟 Key"
npm run dev
```

## 十、上传到仓库

```bash
# 1. 初始化
git init
git add .
git commit -m "feat: 田园小镇首个版本（指令种田 + 村民 AI + 地图/牧场/服装店）"

# 2. 关联远程（换成你的仓库地址）
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
# 或 Gitee： git remote add origin https://gitee.com/<你的用户名>/<仓库名>.git

# 3. 推送
git push -u origin main
```

如果仓库里已经有内容：

```bash
git pull --rebase origin main
git push origin main
```

**可选清理**：`tools/` 里有大量开发时的临时脚本（`probe*.mjs`、`click*.mjs`、`nightdbg*.mjs`、`w2s*.mjs` 等），上传前可以只保留 `serve.mjs`、`build.mjs`、`e2e.mjs`、`smoke.mjs` 和必要的生成脚本，其余删除或移到 `tools/dev/`。

> `.gitignore` 已忽略 `node_modules/`、`dist/`、`release/`；如果需要 GitHub Pages，把 `dist/` 提交上去或直接用仓库根目录（根目录本身就是可运行的静态站点）。
