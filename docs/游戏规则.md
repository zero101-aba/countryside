# 田园小镇 · 游戏规则

> 一句话：你是东家，只发指令；小伟和小杨有自己的性格和想法，自己走过去、自己动手、自己买卖、自己聊天，你全程看得见。

---

## 1. 目标

把荒地变成能自给自足的小镇：

1. 让村民开垦、播种、浇水、收获
2. 卖货换钱，买种子、买面包、雇人（当前版本只有两位主角）
3. 解锁新区域、新指令、新系统
4. 让小伟和小杨的关系发展下去

没有硬性失败。唯一的"惩罚"是村民会饿、会累、会生气、会拒绝干活。

---

## 2. 时间

| 项目 | 规则 |
|---|---|
| 时间流速 | 游戏内 1 小时 = 现实 5 秒；一天约 2 分钟 |
| 速度档位 | 暂停 / 1× / 2× / 4× / 8×（8× 需解锁） |
| 作息 | 23:00 村民回家睡觉，6:00 起床；精力过低会罢工 |
| 夜晚 | 入夜后顶栏出现 🌙，可手动跳到次日 6:00；「夜晚自动跳过」需解锁 |
| 季节 | 每季 28 天，春 → 夏 → 秋 → 冬，冬天作物停长 |
| 天气 | 每天清晨随机：晴 / 雨 / 暴雨 |

---

## 3. 指令

玩家优先：任何自主行为都会在你下令时立刻让位。

| 指令 | 说明 |
|---|---|
| 开垦 / 播种 / 浇水 / 收获 | 对农田；需要走到对应地块 |
| 砍树 / 采集 / 钓鱼 / 挖矿 | 资源点；树 6–10 小时再生，矿 12 小时再生 |
| 收牧产 | 收鸡蛋 / 牛奶 / 羊毛 |
| 吃 / 休息 / 聊天 | 恢复需求或社交 |
| 停下 / 取消 | 清空当前任务和队列 |
| 改令 | 例：`小杨别浇了去钓鱼` — 先停原活再派新活 |

支持自然语言：指定人、批量（`都去浇水`）、范围（`西边`）、序号（`3号地`）、模糊（`浇一下` 会反问补全）。

## 4. 村民

### 4.1 需求

饱食、精力、社交。过低时村民会自己吃饭 / 休息 / 找人聊天；饿到 82 以上或精力低于 10 会中断当前安排。

### 4.2 情绪

喜悦 / 恼火 / 低落 / 不安 / 疲惫，外加对你的信任。

- 干喜欢的活、被夸、吃到东西 → 情绪变好
- 被逼干讨厌的活、挨饿、被冷落 → 情绪变差
- 情绪影响干活速度、拒绝概率和说话语气

### 4.3 性格与自主意愿

| | 小伟 | 小杨 |
|---|---|---|
| 性格 | 嘴甜、心宽、爱清闲、有点懒 | 心细、爱干净、认真、嘴硬心软 |
| 心愿 | 在河边待着，顺便钓两条鱼 | 把地种好，把家里收拾干净 |

没被派活时会自己做：

- 去河边坐坐 / 打盹 / 钓鱼 / 找人聊天（小伟）
- 照看庄稼 / 看花 / 收拾 / 找人聊天（小杨）
- **小杨会自己去集市买种子**（种子 ≤2、白天、钱够）
- **小伟会自己去集市卖库存**（堆了 8 个以上或缺钱）

### 4.4 关系

小伟和小杨有独立关系值 0–100：

- AI 对话、日常相处会增加
- 60 / 75 / 90 触发三段里程碑对话
- 关系 60 解锁「AI 自动对话」

## 7. 农业

- 5 种作物，各有生长时间与适种季节，只在湿润时生长
- 生长四阶段：幼苗 → 生长 → 开花 → 成熟
- 雨天自动浇湿全部地块；暴雨不能钓鱼砍树

---

## 8. 牧场

- 11 种动物：鸡/小鸡、鸭/小鸭、鹅、牛/小牛、羊/小羊、猫、狗
- 鸡鸭鹅下蛋、牛产奶、羊产毛，随时间积累，就绪时头顶出现图标
- 猫狗是陪伴动物
- 收牧产指令需在「牧歌」阶段解锁

## 9. 阶段解锁（核心规则）

每达成一个阶段，永久解锁一块内容；达成时弹出阶段卡片并写入日志。

| 阶段 | 名称 | 达成条件 | 解锁 |
|---|---|---|---|
| 1 | 落脚 | 收获 1 次 | 每日委托板 |
| 2 | 牧歌 | 播种 3 次 | 收蛋 / 挤奶 / 剪羊毛；夜晚自动跳过 |
| 3 | 开市 | 累计收入 150G | 8× 速度 |
| 4 | 进山 | 累计收获 10 次 | 后山林地 + 挖矿 |
| 5 | 渔获 | 累计钓 5 条鱼 | 鲜鱼售价 +20% |
| 6 | 矿工 | 累计挖矿 10 次 | 矿石售价 +30% |
| 7 | 交心 | 小伟与小杨关系 60 | AI 自动对话 |
| 8 | 走遍小镇 | 解锁全部 5 个区域 | 小镇荣誉称号 |

规则说明：

- 阶段只升不降，进度保存在存档里
- 未解锁的功能不会消失，只是暂时不可用：委托按钮隐藏、收牧产指令提示"牧场还没开张"、挖矿提示"后山矿洞还没开"、8× 按钮隐藏
- 「档案」面板显示当前阶段和下一阶段条件
- 阶段与区域解锁、成就相互独立，可以同时推进
